# Description
# Named Entity Recognition using NLP

This project implements Named Entity Recognition (NER) using spaCy.
The system identifies important entities from text such as Person,
Organization, Location, and Date.

## Technologies

- Python
- spaCy
- NLP

## Features

- Entity extraction
- Entity classification
- Entity visualization
- CSV export

## Applications

- Information extraction
- Search engines
- Question answering systems
- Document analysis
